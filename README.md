## 🐒 猴子也能懂的使用指南（只需几步）

如果你这都学不会，那建议把手机捐给有需要的人。

### 第 0 步：准备材料
1. **下载本项目**：点击 [GitHub页面右侧绿色的 `Code` 按钮 -> `Download ZIP`](#)，下载后解压到电脑上。
2. **下载模拟器**：可以用 [MuMu模拟器](https://mumu.163.com/)。
3. **下载维词App**：[点击下载维词APK](https://imtt.dd.qq.com/sjy.00022/sjy.00004/16891/apk/EC254B9AAA616B4D96F4C304CFA5F3EF.apk)，把它安装到你的模拟器或手机上。

### 第 1 步：装环境
找到那个叫 `安装依赖.bat` 的东西，**双击它**。  
*（黑框框刷刷两下就跑完了，不需要等很久！）*

### 第 2 步：起飞
1. 把你的安卓手机/模拟器连上电脑，记得在手机端开启 **“USB调试”**。
2. 双击 `启动.bat`。
3. 丢下手机，该干嘛干嘛去。

## 🔧 高端玩家操作区

如果你觉得“我不是猴子，我想折腾”：
1. 找到 `config.example.py`，把它复制一份，改名为 `config.py`。
2. 自己打开看着里面的注释改大模型配置等等。改崩了别慌，右上角点X，把文件删了重新复制一份。大不了重头再来！

## 🤔 “救命！它不动了！” —— 常见问题自救指南

- **Q：黑框报错提示“找不到设备/初始化失败”？**  
  **A**：拔了数据线重插！如果用的是模拟器，重启模拟器！如果还不行，把电脑也重启了。“重启”是人类解决电子设备问题的终极魔法。

- **Q：万词王模式突然停下来了，并且骂我让我手工选答案？**
  **A**：大模型也有脑抽的时候，如果它没找到答案（比如它看不懂英译汉），程序会暂停呼唤主人的援助。用你尊贵的手指随便选一个正确答案，**然后在黑框框里按下回车（Enter）键**，程序马上就会继续干活。
